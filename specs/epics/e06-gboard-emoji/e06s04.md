# e06s04 — Dynamic scaling, compact search, 4x1 search pad

## Dynamic scaling (floating + docked)

- `EmojiPicker` wraps content in `BoxWithConstraints`: grid width is
  `maxWidth - 56.dp pad`; columns = `(gridWidth / 48.dp).coerceIn(3, 8)`;
  emoji font = `cell * 0.52`. Narrow floating widths drop to 3-4 columns
  with readable glyphs; full-width docked goes up to 8. No fixed `sp`.
- The 4 pad keys use `weight(1f)` to split whatever height the caller gives
  (`emojiPickerHeight` / `keyboardHeight`), so floating and docked both fill.

## Compact search field

- `OutlinedTextField` is `readOnly` (tapping must not summon a system
  keyboard from inside the IME), 13sp hint / 14sp text, tight padding,
  trailing clear-X only when the query is non-empty.

## 4x1 vertical search pad (`emoji/EmojiSearchPad.kt`)

- 56dp strip docked right of the grid, inside the picker: 3 alpha keys with
  full 8-way swipes (27 slots = a-z + space; centers e/o/space) + 1 action
  key (center/tap = backspace, top = backspace, right = clear, bottom = commit
  top result, left = ABC/exit to MAIN).
- Custom `awaitEachGesture` tap-vs-drag resolver (12dp threshold, 8 angle
  sectors); this is why the search field is typeable at all — as the IME,
  no system keyboard can feed it.
- `EmojiPicker` gains `onExitEmoji: () -> Unit` (KeyboardScreen sets
  `mode = MAIN`) and `vibrateOnTap`.
