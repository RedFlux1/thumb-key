# e06s03 — MRU recents + drop emoji2 dependency

Port Gboard's recents/history concept without Room migration.

## Recents (`ui/components/keyboard/emoji/EmojiRecentsStore.kt`)

- Private `SharedPreferences` file `emoji_recents` (no exported provider,
  consistent with clipboard `usePrivateClipboard` posture).
- `getRecents(): List<String>` (max 40, MRU first), `push(emoji: String)`:
  dedupe, prepend, trim. Synchronous `apply()`.
- Caller (`KeyboardScreen`) owns store via `remember(ctx)`, holds
  `var recents` state, refreshes after each pick.

## Cleanup

- Remove `implementation("androidx.emoji2:emoji2-emojipicker:1.6.0")` from
  `app/build.gradle.kts`.
- No DB migration (recents are prefs, not Room).
- Kitchen stays deferred: no `EmojiKitchen*` classes, no ranker JNI stub.

## Verify

- `./gradlew lintKotlin lint assembleDebug`
- Manual: pick 3 emoji, reopen picker, Recents tab shows MRU order;
  relaunch IME, recents persist.
