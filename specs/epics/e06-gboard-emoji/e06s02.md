# e06s02 — Compose EmojiPicker + KeyboardScreen swap

Port Gboard's HEADER/BODY picker split to pure Compose (fixes the
`SubcomposeLayout` + `AndroidView(EmojiPickerView)` overlay crash).

## Picker (`ui/components/keyboard/emoji/EmojiPicker.kt`)

- `@Composable fun EmojiPicker(onEmojiPicked: (String) -> Unit, recents: List<String>, modifier: Modifier)`.
- Header: search `TextField` + horizontally scrollable category chips
  (Recents when non-empty, Search-results pseudo-tab when query non-blank,
  then SMILEYS/GESTURES/HEARTS/NATURE/FOOD/OBJECTS/SYMBOLS).
- Body: `LazyVerticalGrid(columns = 8)` of system-font `Text` buttons
  (`~28.sp`), no `AndroidView`, no Bitmap pipeline (replaces
  `EmojiView`/`FixedSizeEmojiListHolder`/`PageableEmojiListHolderView` with
  Compose equivalents).
- Pure: recents passed in, no context/store inside; caller owns persistence.

## KeyboardScreen swap

- Both `KeyboardMode.EMOJI` branches keep their shells:
  - custom `modes.emoji` layout: picker height `keyHeight*(rows-1)` + layout
    bottom row as functional row (unchanged behavior);
  - default: picker full height + `controllerKeys` side column (unchanged).
- Replace each `AndroidView(factory={ EmojiPickerView... })` block with the new
  `EmojiPicker`, preserving haptic/sound + `commitText(emoji, 1)` in one
  shared `pick()` handler.
- Remove `androidx.emoji2.emojipicker.EmojiPickerView` + `AndroidView` imports.

## Verify

- `./gradlew lintKotlin lint assembleDebug`
- Manual docked + floating: open EMOJI mode, search, switch tabs, tap commits.
