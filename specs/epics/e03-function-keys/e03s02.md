# e03s02 — Add Fn Toggle to Programmer Keyboard Layouts

Add the Fn toggle key (TOGGLE_FN_TRUE_KEYC) to all programmer/variant keyboards
as a swipe action, following the same pattern as Ctrl and Alt toggles.

## Tasks

### 1. Add TOGGLE_FN_TRUE_KEYC and TOGGLE_FN_FALSE_KEYC to CommonKeys.kt

- Add to CommonKeys.kt, following the pattern of TOGGLE_CTRL_TRUE_KEYC:

```kotlin
val TOGGLE_FN_TRUE_KEYC =
    KeyC(
        display = KeyDisplay.IconDisplay(Icons.Outlined.SmartButton),
        action = ToggleFnMode(true),
        color = MUTED,
    )

val TOGGLE_FN_FALSE_KEYC =
    KeyC(
        display = KeyDisplay.IconDisplay(Icons.Outlined.KeyboardDoubleArrowDown),
        action = ToggleFnMode(false),
        color = MUTED,
    )
```

- Use `Icons.Outlined.SmartButton` or the best available Material icon for Fn.
  If no suitable icon exists, use `KeyDisplay.TextDisplay("Fn")`.

**verify:** `./gradlew lintKotlin` — no compilation errors

### 2. Add Fn toggle to ENThumbKeyProgrammer.kt

- On the spacebar (SPACEBAR_PROGRAMMING_KEY_ITEM), add Fn on an available
  swipe direction. The spacebar already has:
  - topLeft/bottomLeft/bottomRight → Ctrl/Alt/prevWord/nextWord
  - left/right/top/bottom → arrow keys
- Add Fn on topRight if available, otherwise find the best placement

**verify:** `./gradlew lintKotlin`

### 3. Add Fn toggle to ENThumbKeyProgrammerExpanded.kt

- Same approach — add TOGGLE_FN_TRUE_KEYC to the spacebar or a modifier key

**verify:** `./gradlew lintKotlin`

### 4. Add Fn toggle to remaining programmer keyboards

- ENThumbKeyProgrammerWide.kt
- NOThumbKeyDataDriven.kt (already has Ctrl/Alt on spacebar — add Fn)
- NOThumbKeyDataDrivenExpanded.kt
- ENTypeSplitProgramming.kt
- ENSVThumbkeyProgrammer.kt
- CZProgrammerMessagEase.kt

**verify:** `./gradlew lintKotlin`

### 5. Add Fn to all keyboards that already have Ctrl/Alt/Meta toggles

- ENMessagEaseSymbolsModifiers.kt and any other keyboard that exposes
  modifier toggles should also get Fn for consistency.
- Check each keyboard that references TOGGLE_CTRL_TRUE_KEYC or
  TOGGLE_ALT_TRUE_KEYC or TOGGLE_META_TRUE_KEYC.

**verify:** `./gradlew lintKotlin`
