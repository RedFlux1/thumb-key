# e04s01 — Rich Clip model + Room v2 + UNIQUE dedupe

Extend `ClipboardItem` to Gboard `clips` parity (text-only columns first,
image uri plumbing in s02):

- `htmlText: String?`
- `itemType: Int` (0=text default, 1=image, 2=rich/html; matches Gboard `item_type`)
- `entityType: Int` default 0 (Gboard `entity_type`, reserved for future NER)
- `uri: String?` (content/file uri string for image clips, null for text)
- `sensitive: Boolean` default false (API33 `IS_SENSITIVE` + password-field heuristic)
- `groupId: Int` default 0 (Gboard `group_id`, reserved)
- Keep `id`, `text`, `timestamp`, `isPinned`.

DAO changes (`ClipboardItemDao`):
- `findByUnique(text, htmlText, uri)` for `UNIQUE(text,html_text,uri)` semantics
- `getAllClipboardItems()` ordering unchanged: `is_pinned DESC, timestamp DESC`
- `insert(onConflict=REPLACE)` unchanged (covers Gboard `ON CONFLICT REPLACE`)

Repository (`ClipboardRepository.addItem` overload):
- `addItem(text, htmlText=null, itemType=0, entityType=0, uri=null, sensitive=false, groupId=0)`
- Dedupe via `findByUnique` (null-safe: `COALESCE`), bump timestamp on hit
- Preserve `isPinned` on dedupe bump
- `clearExpired()` must NOT delete pinned; sensitive clips follow normal expiry (saved with flag per decision)

Migration:
- `ClipboardDB` version 1->2, `MIGRATION_1_2`: `ALTER TABLE ClipboardItem ADD COLUMN ...` for each new col with NOT NULL defaults where applicable
- Add `schemas/` JSON export update (Room `exportSchema=true`)

- `./gradlew lintKotlin`
- `./gradlew assembleDebug`
- Manual: copy text, verify row has itemType=0, sensitive=false
