# e04s03 — Paste parity (text/html/image) + private provider

Paste path mirrors Gboard `fmx.d()` (text) / `fmx.i()` (image):

- `KeyboardScreen` `onItemClick/onItemPaste`:
  - If `item.uri != null && item.text.isBlank()` (image clip): call `ctx.currentInputConnection.commitContent(...)` with `ClipDescription(mimeType)` when `Build.VERSION.SDK_INT>=25` and `EditorInfo.contentMimeTypes` allows it; fallback to system `performContextMenuAction(paste)` with Toast on unsupported (mirrors Gboard banner `fnc` path)
  - Else (text): `commitText(item.text, 1)` unchanged; if `item.htmlText != null` still commit plain text (no styled commit in IME; html retained for dedupe/future)
- `Utils.kt Paste` action: when private clipboard and last clip is image (`clipboardGetLastClip` returns text? extend manager with `getLastImageClip(): ClipboardItem?`), route to same commitContent path; else existing text path
- `ThumbKeyClipboardManager`: expose `getLastClipItem(): ClipboardItem?` ( richest recent: query DAO `getLatest()` ), keep `getLastClip(): String?` for compat

ContentProvider (non-exported, mirrors Gboard):
- New `ThumbKeyClipboardProvider : ContentProvider`:
  - `authority = "${applicationId}.clipboard_content"`
  - `UriMatcher`: `clips` -> 2 (dir), `clips/#` -> 1 (item)
  - `getType`: `vnd.android.cursor.dir/clips` / `vnd.android.cursor.item/clips`
  - `query` only dir with projection/selection/sort passthrough to DAO via Cursor (use `MatrixCursor` from Room rows)
  - `insert/delete/update` via repository (blocking runBlocking for provider contract, IO dispatcher)
  - `onCreate` returns true; `exported=false` in manifest
- `AndroidManifest.xml`: `<provider android:name=".db.ThumbKeyClipboardProvider" android:authorities="${applicationId}.clipboard_content" android:exported="false" />`
- `ClipboardContentUris.kt`: `buildClipsUri(context)`, `buildClipUri(context,id)` (mirrors `fmb.d`)

Verify:
- `./gradlew lintKotlin lint assembleDebug`
- Tap text clip -> commits text; tap image clip in supported editor (e.g. Messages) -> image commits; unsupported editor -> toast, no crash
- `adb shell content query --uri content://com.dessalines.thumbkey.debug.clipboard_content/clips` returns rows (debug build)
